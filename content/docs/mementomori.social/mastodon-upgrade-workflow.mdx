Mastodon upgrades run through the [upgrade workflow automation](https://github.com/mementomori-social/upgrade-workflow-automation) scripts. Its README has every step and setting.

<GitHubCard url="https://github.com/mementomori-social/upgrade-workflow-automation" />

### Test on the development environment

Run the local script as the `mastodon` user:

```bash
cd ~ && (test -d upgrade-workflow-automation && cd upgrade-workflow-automation && git pull || git clone https://github.com/mementomori-social/upgrade-workflow-automation.git) && cd ~/upgrade-workflow-automation && bash mastodon-upgrade-local.sh
```

It shows how far our [fork](https://github.com/mementomori-social/mastodon) is behind Mastodon, syncs it, creates a new dated `mementomods` branch, merges our changes from the previous branch, then builds and starts everything for testing. When the upgrade works, the new branch is pushed to GitHub.

### Install on production

On the Mastodon server, as the `mastodon` user:

```bash
cd ~ && (test -d upgrade-workflow-automation && cd upgrade-workflow-automation && git pull || git clone https://github.com/mementomori-social/upgrade-workflow-automation.git) && cd ~/upgrade-workflow-automation && bash mastodon-upgrade-production.sh
```

The script requires a database backup before it continues, then pulls the new branch, builds the assets, runs the database migrations with confirmations, rebuilds the search index when needed and restarts the services. It also prompts for the status page update and the upgrade announcement.

Mastodon Bird UI is updated separately with `bash mastodon-bird-ui-update.sh` when it has new changes.
